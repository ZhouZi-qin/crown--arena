# 皇室对决 · 双人对战联机说明

这份说明同时适用主机和客机，照着做即可对战。

## 第一步：安装 / 运行游戏

解压后双击 **`皇室对决便携版.exe`** 即可运行，不用安装。
（主机如果想装到电脑里，也可以用安装包，但双方**游戏版本要一致**，最稳妥是都用这份包里的便携版。）

## 第二步：确保在同一局域网

双方必须连**同一个 WiFi / 路由器**（或其中一人开热点，两人连它）。手机热点也行。

## 第三步：主机放行防火墙端口（重要，否则对方连不上）

这一步**主机必须做**，客机一般不用做。用管理员权限打开命令行执行一条命令即可：

1. 按 `Win + S`，搜索 `PowerShell`，在结果上**右键 → 以管理员身份运行**
2. 在弹出的窗口里粘贴下面这行命令，回车：

```
netsh advfirewall firewall add rule name="皇室对决 联机端口 38271" dir=in action=allow protocol=TCP localport=38271 profile=private
```

3. 看到「确定。」就成功了。（这条规则只在专用网络生效，不影响公共网络安全。）

> 如果不想用命令行，也可以走图形界面：Windows 安全中心 → 防火墙和网络保护 → 高级设置 → 入站规则 → 新建规则 → 端口 → TCP → 特定本地端口填 `38271` → 允许连接 → 只勾选「专用网络」→ 名称随意，完成。

## 第四步：建房 + 加入

1. 双方打开游戏，在主菜单点「**双人对战（局域网）**」
2. **主机**点「**创建房间（主机）**」，屏幕上会显示 IP 地址（形如 `192.168.x.x`），把它发给对方
3. **客机**在输入框里**只填 IP**（不要带端口，不要填 `127.0.0.1`），点「**加入房间（客机）**」
4. 双方自动开战

## 常见问题

- **客机一直连不上 / 提示超时？** 九成是主机没做第三步的防火墙放行；确认双方在同一局域网；主机创建房间后不要关掉游戏。
- **输入的 IP 从哪来？** 主机创建房间后，界面「把下面任一地址告诉对手」那一栏显示的就是。有多行时任选一行发给你。
- **画面是镜像的？** 正常。客机画面由主机同步而来，你永远在下方，操作方式和单人一样，以主机画面为准。
- **主机中途退出？** 房间会断开，需要主机重新创建房间、客机重新加入。

## 键盘操作

- `1`~`4` 选牌，`空格` 暂停
